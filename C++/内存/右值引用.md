## 常规的引用

```cpp
void DemoSort(vector<int>& v) {
    sort(v.begin(), v.end());

}
int main()
{
    vector<int> v = { 4,1,2,6,3,5,8,7 };
    DemoSort(v);
    for (auto i : v) {
        cout << i << ' ';
    }
    cout << endl;
}
```

当我们把`DemoStart`的参数改为右值引用，且传递v的方式变为 `std::move` 
```cpp
void DemoSort(vector<int>&& v) {
	sort(v.begin(), v.end());
}
int main()
{
    vector<int> v = { 4,1,2,6,3,5,8,7 };
    DemoSort(std::move(v));
    for (auto i : v) {
        cout << i << ' ';
    }
    cout << endl;
}
```

## 值类别

表达式分为三种类型： **lvalue** , **xvalue** 和 **prvalue**
1. lvalue 为左值，left 表示一个有“身份”的对象，可以持续找到它
![[C++/内存/assets/a9ce2a96062c2d5944a5dd4c29e2fb17_MD5.jpg]]

2. prvalue为纯右值，我们不关心它的身份，只关心值的 “临时结果” 
![[C++/内存/assets/4cf19240c43605a54baeec02bd7dbe01_MD5.jpg]]

3. `xvalue` 将亡值
```cpp
int a;
std::move(a); // 这个返回值就是将亡值 xvalue
```
`std::move`的实现很简单，只有一行
```cpp
template <class T>
constexpr remove_reference_t<T>&& move(T&& Arg) noexcept {
	return static_cast<remove_reference_t<T>&&>(Arg);
}
```
我们发现`std::move` 接收的参数类型是一个 `T&&` ，那这又是什么类型？为什么能接收我们的左值 ？
### 万能引用

**核心机制：类型推导 + 引用折叠**

类型推导：模板实参推导对这种形参 `T&&` 有一条特殊规则：
- 若实参是左值：推导 T 为 U&
- 若实参是右值：推导 T 为 U（非引用）


比如下列代码
我们调用 `int a; f(a);` 这里a是lvalue，会推导出 T = int&，于是参数类型变成 int& &&，按“引用折叠”规则折叠为 int&
假如调用 `f(10);` 10是prvalue，会推导出 T = int，于是参数类型是 int&&
```cpp
template<class T>
void f(T&& x); // 这里的 T&& 是万能/转发引用
```

> 为什么不会推导成 T = int&&？***(这里感觉解释不通顺)***
> 因为 T 是模板参数本体，推导时会先确定 T，再把它代回原型形成最终参数类型。对右值实参，规则就是“T 推成非引用类型 U”，这样才能让 T&& 最终得到 U&&。
> 相反，对左值实参如果也推成 U，那 T&& 会变成 U&&，就会让左值也绑定到右值引用，破坏“必须显式 std::move 才能把左值当右值用”的语义。因此标准规定：左值实参时把 T 推成 U&，再通过引用折叠把 U& && 折叠为 U&，从而保留左值属性。


引用折叠：
```cpp
•	&  &  -> &  // 两个左值合并为左值
•	&  && -> &  // 一个左值一个右值合并为左值
•	&& &  -> &  // 一个左值一个右值合并为左值
•	&& && -> && // 两个右值合并为右值
```
即为 ***有左即左，全右才右***

- 什么时候 T&& 不是万能引用?
1.  不是推导出来的 T
```cpp
template<class T>
struct S {
    void g(T&&); // 这里通常不是万能引用：T 在类模板实例化时就固定了，不在 g() 调用点推导
};
```
2. 发生了“别的形式”，不再是裸 T&&
```cpp
template<class T>
void h(std::vector<T>&&); // 不是万能引用，这是纯右值引用
```
3. 明确写死类型
```cpp
void k(int&&); // 纯右值引用
```


## 重要概念

1. 返回右值引用&& 的函数，值类别为`xvalue`
2. `std::move`除了返回右值引用外，不会做其它任何事情（这也就是为什么v还能继续被打印的原因）
3. `xvalue` 本质上还是左值，只是被贴上了”语义“标签的左值，对于一个对象来说，绑定到其身上的左值还是右值都没有区别，都是对a的一个别名
```cpp
int a = 10;
int ra = &a;
int rra = &&a;
cout << a <<endl; // 10
ra = 11;
cout << a <<endl; // 11
rra = 12;
cout << a <<endl; // 12
```
4.  右值引用可以是绑定到`xvalue`,或`prvalue`的引用；左值引用是必须绑定到`lvalue`的引用
