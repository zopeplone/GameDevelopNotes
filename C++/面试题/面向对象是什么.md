# 面向对象概念

它把**现实世界**中的事物抽象为 **对象（Object）**，对象由：
- **属性（State）**：对象的数据
- **行为（Behavior）**：对象可以执行的操作
在 C++ 中通常通过 **类（class）** 来描述对象
面向对象核心有三个特性：
1. **封装（Encapsulation）**
2. **继承（Inheritance）**
3. **多态（Polymorphism）**

# 1. 封装
封装是指：
> **把数据和操作数据的函数封装在一个类中，并对外隐藏实现细节。**

在 C++ 中主要通过：
- `private`
- `protected`
- `public`
访问控制实现。优点： 隐藏内部实现，防止非法修改数据，降低模块耦合

# 2.继承（Inheritance）
继承是：
> **一个类可以继承另一个类的属性和行为，从而实现代码复用。**

-  代码复用：子类可以直接使用父类的成员函数和成员变量。
- 建立类层次结构：继承可以表达 **“is-a”关系**。
# 3.多态（Polymorphism）
多态是：

> **同一个接口，不同对象有不同实现。**

C++ 中主要通过：

- **虚函数（virtual function）**
- **函数重写（override）**
- **基类指针调用**
## C++多态的底层机制
### 编译时多态
函数和运算符的重载

### 运行时多态
当类中存在 `virtual` 函数时：
- 编译器会为类生成 **虚函数表（vtable）**
- 对象中会有一个 **vptr 指针**
- 指向该类的 vtable
调用虚函数时：
对象 -> vptr -> vtable -> 函数地址
这样就能在 **运行时确定函数实现**。
这就是 **动态绑定（dynamic binding）**

> 只有通过指针或者引用的方式调用虚函数是运行时确定，通过值调用的虚函数是编译期就可以确定的

- 虚函数是存在类中还是类对象中（即是否共享虚表）？
存在类中，不同的类对象共享一张虚函数表(为了节省内存空间)。
