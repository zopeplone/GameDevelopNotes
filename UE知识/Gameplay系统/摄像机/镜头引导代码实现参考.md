# 镜头引导代码实现参考

## 本版分工和调用约定

本版把 Guidance 的绝大部分逻辑和所有业务运行时状态放入 UCameraGuidanceModifier：请求校验、权限判断、优先级、目标、Preset、阶段时间、构图、输入解释、交接与恢复策略。Manager 只保存 Modifier 实例，转发公开接口并提供相机管线桥接，不再保存 ActiveRequest 或 Phase。

所有运行时状态只在 ModifyCamera 中推进；ProcessControlRotation 消费待同步旋转。需要注意：只有 Camera Manager 正在进行真实 ViewTarget 过渡时，ModifyCamera 才可能针对不同 POV 重复调用；当前版本暂不加入帧去重，代码按每次调用推进状态。

此版本将 GuidanceModifier 注册为普通 UGC Camera Modifier，由 Camera Manager 自动调用 ModifyCamera。Manager 不调用 Advance，不调用 SetViewTarget；真实 ViewTarget 始终保持玩家。Hard 的 Guidance ViewTarget 只是 Modifier 内部保存的目标语义。此方式不使用引擎 Modifier Alpha/禁用生命周期，统一由 Modifier 自己的阶段驱动；不要混用 DisableModifier 当作取消 Guidance。

Soft 和 Hard 都保持玩家真实 ViewTarget；Hard 使用 Modifier 内部的逻辑 Guidance ViewTarget 目标 Actor，不创建代理、不写入真实 ViewTarget。角色/镜头输入和高层权限由外部系统提交到 Manager 再转发。

代码是重构参考，未在项目模块编译或实机验证。沿用上一版列出的基础实现限制，不能直接当成全部需求均已满足的生产代码。文件置于同一游戏模块，依赖 AuroraDevs_UGC、Engine、Core、CoreUObject；项目现有 UGC 蓝图 Manager 需重新指定父类并保留原有配置。

## CameraGuidanceModifier.cpp

```cpp
#include "CameraGuidanceModifier.h"
#include "CameraGuidanceManager.h"
#include "GameFramework/PlayerController.h"
#include "GameFramework/Pawn.h"
#include "Engine/World.h"
#include "EngineGlobals.h"


ACameraGuidanceManager* UCameraGuidanceModifier::Host() const
{ return CastChecked<ACameraGuidanceManager>(CameraOwner); }
APlayerController* UCameraGuidanceModifier::PC() const
{ return Host()->GetOwningPlayerController(); }
bool UCameraGuidanceModifier::ModifyCamera(float DT, FMinimalViewInfo& POV)
{
    // 正常注册在 ModifierList；不手动调用本函数。
    if (Phase == EPhase::Idle) return false;
    if (!bAllowed || !PC() || !PC()->GetPawn() ||
        !ReturnTarget.IsValid() || GetViewTarget() != ReturnTarget.Get() ||
        Host()->HasPendingViewTargetBlend())
    { Reset(); return false; }
    // 此专用完整 POV 重载不调用 UGC Super，避免额外属性处理和缓存输入覆盖。
    // 状态 Alpha、输入和权限均由本类显式管理。
    TickGuidance(DT, POV);
    InputLook = FRotator::ZeroRotator;
    if (Phase != EPhase::Idle) POV = OutputPOV;
    // Hard 不是“截断其他 Modifier”的同义词。后续修正由项目排序管理。
    return false;
}
void UCameraGuidanceModifier::Shutdown()
{
    Reset();
}
bool UCameraGuidanceModifier::Resolve(FVector& Out) const
{
    if (bPoint) { Out = Point; return !Out.ContainsNaN(); }
    if (!Target.IsValid()) return false;
    FVector E;
    Target->GetActorBounds(false, Out, E);
    return !Out.ContainsNaN();
}

void UCameraGuidanceModifier::SubmitInput(FVector2D Move, FRotator Look)
{
    bMoving = Move.SizeSquared() > 0.01f; // 接入经过设备死区处理的轴
    InputLook = Look;
    if (!bHard && (Phase == EPhase::Enter || Phase == EPhase::Hold)
        && !Look.IsNearlyZero(0.001f)) CancelCameraGuidance();
}

bool UCameraGuidanceModifier::RequestCameraGuidance(const FCameraGuidanceRequest& R)
{
    if (!PC() || !PC()->GetPawn() || !bAllowed || !R.Preset) return false;
    if (Phase != EPhase::Idle) // 包括交接阶段，先拒绝非更高优先级请求
        if (!Preset || R.Preset->Priority <= Preset->Priority) return false;
    if (Host()->HasPendingViewTargetBlend()) return false; // 基础版不抢占正在进行的 Blend
    const auto& P = *R.Preset;
    if (P.Mode == ECameraGuidanceMode::Soft && !InputLook.IsNearlyZero()) return false;
    if (P.EnterSeconds <= 0 || P.ExitSeconds <= 0 || P.HoldSeconds < 0 ||
        P.HorizontalFOV <= 5 || P.HorizontalFOV >= 150 ||
        P.FrameMargin <= 0 || P.FrameMargin >= 0.45f ||
        P.MinDistance <= 0 || P.MaxDistance < P.MinDistance || P.TargetRadius < 0)
        return false;
    FVector T = R.WorldPoint;
    if (!R.bWorldPoint)
    {
        if (!IsValid(R.TargetActor)) return false;
        FVector E; R.TargetActor->GetActorBounds(false, T, E);
    }
    FMinimalViewInfo Test = Host()->GetCameraCacheView();
    const float Yaw = P.Mode == ECameraGuidanceMode::Hard
        ? (IsValid(R.TargetActor) ? R.TargetActor->GetActorRotation().Yaw : 0.f)
        : Test.Rotation.Yaw;
    if (!Solve(GetWorld(), PC()->GetPawn(), R.TargetActor, T,
        P, Yaw, Test.AspectRatio, Test)) return false;
    if (Phase == EPhase::Idle) ReturnTarget = GetViewTarget();
    // 抢占保留最初的 ReturnTarget，不将旧 Guidance 当返回目标。
    StartPOV = Host()->GetCameraCacheView();
    OutputPOV = StartPOV;
    Preset = R.Preset;
    Target = R.TargetActor;
    bPoint = R.bWorldPoint || !P.bTrackTarget;
    Point = T;
    ViewYaw = Yaw;
    bHard = P.Mode == ECameraGuidanceMode::Hard;
    Phase = EPhase::Enter; Elapsed = 0;
    bPendingControlRotationSync = false;
    bFinishAfterSync = false;
    bCancelRequested = false;
    // Hard 仅记录逻辑 Guidance ViewTarget，不切换真实 ViewTarget。
    return true;
}

void UCameraGuidanceModifier::CancelCameraGuidance()
{
    if (Phase == EPhase::Enter || Phase == EPhase::Hold)
        bCancelRequested = true; // 在 ModifyCamera 内进入 Returning
}

void UCameraGuidanceModifier::BeginReturning()
{
    ReturningStartPOV = Host()->GetCameraCacheView();
    OutputPOV = ReturningStartPOV;
    Phase = EPhase::Returning;
    Elapsed = 0.f;
    bCancelRequested = false;
    bPendingControlRotationSync = false;
}

void UCameraGuidanceModifier::SetGuidanceAllowed(bool Allowed)
{
    bAllowed = Allowed;
    if (!Allowed) Reset(); // 高层系统自行接管真实 ViewTarget
}

void UCameraGuidanceModifier::Reset()
{
    Phase = EPhase::Idle;
    Preset = nullptr;
    Target.Reset(); ReturnTarget.Reset();
    bHard = false;
    bPendingControlRotationSync = false;
    bFinishAfterSync = false;
    bCancelRequested = false;
}

void UCameraGuidanceModifier::TickGuidance(float DT, FMinimalViewInfo& BasePOV)
{
    if (!PC() || !PC()->GetPawn()) { Reset(); return; }
    if (Phase == EPhase::AwaitSync) return;
    if (bCancelRequested) BeginReturning();
    if (Phase == EPhase::Enter || Phase == EPhase::Hold)
    {
        FVector T;
        FMinimalViewInfo Desired = BasePOV;
        if (!Resolve(T) || !Solve(GetWorld(), PC()->GetPawn(), Target.Get(), T,
            *Preset, ViewYaw, BasePOV.AspectRatio, Desired))
            BeginReturning();
        else
        {
            Elapsed += DT;
            OutputPOV = Desired;
            if (Phase == EPhase::Enter)
            {
                float A = FMath::Clamp(Elapsed/Preset->EnterSeconds,0.f,1.f);
                A = Preset->EnterCurve ? FMath::Clamp(
                    Preset->EnterCurve->GetFloatValue(A),0.f,1.f) : A*A*(3.f-2.f*A);
                OutputPOV = StartPOV;
                OutputPOV.BlendViewInfo(Desired,A);
                if (Elapsed >= Preset->EnterSeconds)
                { OutputPOV = Desired; Phase = EPhase::Hold; Elapsed = 0.f; }
            }
            else if (Elapsed >= Preset->HoldSeconds) BeginReturning();
        }
    }
    if (Phase == EPhase::Returning)
    {
        Elapsed += DT;
        float A = FMath::Clamp(Elapsed/Preset->ExitSeconds,0.f,1.f);
        A = A*A*(3.f-2.f*A);
        // 使用本次输入的普通玩家 POV，不使用上帧相机缓存作为返回终点。
        OutputPOV = ReturningStartPOV;
        OutputPOV.BlendViewInfo(BasePOV,A);
        if (Elapsed >= Preset->ExitSeconds)
        {
            OutputPOV = BasePOV;
            Phase = EPhase::AwaitSync;
            bFinishAfterSync = true;
            bPendingControlRotationSync = true;
        }
    }
    // Enter/Hold 无移动时可同步；Hard 的机位计算不读取此控制旋转。
    if ((Phase == EPhase::Enter || Phase == EPhase::Hold) && !bMoving)
        bPendingControlRotationSync = true;
}

bool UCameraGuidanceModifier::ProcessControlRotation_Implementation(
    AActor* ViewTarget, float DeltaTime, FVector InViewLocation,
    FRotator InViewRotation, FRotator InLocalControlRotation,
    FRotator InDeltaRot, FRotator& OutDeltaRot)
{
    bBlockRotationThisCall = Phase != EPhase::Idle;
    OutDeltaRot = InDeltaRot;
    if (!bBlockRotationThisCall) return false;
    // Returning 完成请求不能因持续移动被撤销；保持阶段的无移动同步需重查输入。
    if (bPendingControlRotationSync && (bFinishAfterSync || !bMoving))
    {
        // 此时读取上一轮完整相机缓存，包含 Guidance 后续 Modifier 的输出。
        PendingControlRotation = CameraOwner->GetCameraRotation();
        OutDeltaRot = (PendingControlRotation-InViewRotation).GetNormalized();
        const bool bDone = bFinishAfterSync;
        bPendingControlRotationSync = false;
        if (bDone) Reset();
    }
    else
    {
        OutDeltaRot = FRotator::ZeroRotator;
        bPendingControlRotationSync = false;
    }
    // 不直接 SetControlRotation；PlayerController 随后写回计算结果。
    return true;
}

bool UCameraGuidanceModifier::ModifyFullControlRotation_Implementation(
    AActor* ViewTarget, float DeltaTime, FVector InViewLocation,
    FRotator InControlRotation, FRotator& OutControlRotation)
{
    OutControlRotation = InControlRotation;
    // UGC 基类将两个钩子的返回值做 AND；同步消费后仍需保留本次阻断标志。
    return bBlockRotationThisCall;
}

bool UCameraGuidanceModifier::Solve(UWorld* World, AActor* Player,
    AActor* TargetActor, const FVector& TargetPoint,
    const UCameraGuidancePresetDataAsset& P, float Yaw,
    float Aspect, FMinimalViewInfo& Out) const
{
    if (!World || TargetPoint.ContainsNaN()) return false;
    const bool bSoft = P.Mode == ECameraGuidanceMode::Soft;
    FVector Origin=FVector::ZeroVector, Extent=FVector::ZeroVector;
    if (bSoft)
    {
        if (!Player) return false;
        Player->GetActorBounds(false, Origin, Extent);
    }
    TArray<FVector> Points;
    // 八角点保证玩家包围盒在安全画幅内；目标使用半径包围盒。
    auto AddBox = [&Points](FVector C, FVector E)
    {
        for (int X : {-1, 1}) for (int Y : {-1, 1}) for (int Z : {-1, 1})
            Points.Add(C + FVector(X*E.X, Y*E.Y, Z*E.Z));
    };
    if (bSoft) AddBox(Origin, Extent);
    AddBox(TargetPoint, FVector(P.TargetRadius));
    const FVector Center = bSoft ? (Origin + TargetPoint)*0.5f : TargetPoint;
    const FRotator R(P.ViewPitch, Yaw + P.YawOffset, 0.f);
    const FRotationMatrix Basis(R);
    const FVector F = Basis.GetUnitAxis(EAxis::X);
    const FVector Right = Basis.GetUnitAxis(EAxis::Y);
    const FVector Up = Basis.GetUnitAxis(EAxis::Z);
    const float TX = FMath::Tan(FMath::DegreesToRadians(P.HorizontalFOV*0.5f));
    const float TY = TX / FMath::Max(Aspect, 0.1f);
    const float Safe = 1.f - 2.f*P.FrameMargin;
    float D = bSoft ? P.MinDistance : P.HardDistance;
    for (const FVector& Point : Points)
    {
        const FVector V = Point-Center;
        D = FMath::Max(D, FMath::Max(
            FMath::Abs(V|Right)/(TX*Safe),
            FMath::Abs(V|Up)/(TY*Safe)) - (V|F));
    }
    if (D > P.MaxDistance) return false;
    FVector Position = Center - F*D;
    FCollisionQueryParams Q(SCENE_QUERY_STAT(CameraGuidance), false);
    if (Player) Q.AddIgnoredActor(Player);
    if (TargetActor) Q.AddIgnoredActor(TargetActor);
    FHitResult Hit;
    // 保守策略：所选机位路径碰撞即拒绝，而非穿墙或牺牲构图。
    if (World->SweepSingleByChannel(Hit, Center, Position, FQuat::Identity,
        ECC_Camera, FCollisionShape::MakeSphere(12.f), Q)) return false;
    if (World->LineTraceSingleByChannel(Hit, Position, TargetPoint,
        ECC_Visibility, Q)) return false;
    if (bSoft && World->LineTraceSingleByChannel(Hit, Position, Origin,
        ECC_Visibility, Q)) return false;
    Out.Location = Position;
    Out.Rotation = R;
    Out.FOV = P.HorizontalFOV;
    Out.AspectRatio = Aspect;
    return true;
}
```

## 接入与时序约束

1. 在现有游戏模块中放入这些文件，依赖 Core、CoreUObject、Engine、AuroraDevs_UGC。现有 UGC 蓝图 Camera Manager 改继承项目 Manager，保留原配置。这里只更新代码文档，没有改插件源码或构建项目。
2. GetGuidance 通过 AddNewCameraModifier 注册实例；不再 NewObject 后手动调度。不要在 DefaultModifiers 中再配第二个同功能实例。
3. Guidance 的控制旋转顺序需早于其他会写旋转的 Modifier。建议项目明确分配 Priority（例如 0），避开同级 Exclusive 冲突；不是把请求 Priority 当成 Modifier Priority。当前构造默认 127 必须在类默认值或构造函数按项目顺序调整。
4. 输入系统每帧在 UpdateRotation 前提交去死区的 Move 和本帧 Look。Manager 仅转发；在顶墙时也要保持 Move 非零。所有取消、权限接管均从外部事件直达 Modifier，避免禁用后等待下一次 ModifyCamera 清理。
5. Sequence、战斗 Focus、瞄准、外部真实 ViewTarget Blend 开始前提交不允许 Guidance。Hard Guidance 自身不切换真实 ViewTarget。真实 ViewTarget 发生过渡时，UE 可能对不同 POV 调用 Modifier；当前版本仅在文档中提醒，代码暂不做帧去重。
6. ModifyCamera 是唯一持续推进入口；请求初始化和 ProcessControlRotation 消费同步会更新必要标志，但 Manager 不推进阶段。每次 ModifyCamera 调用都会推进一次。生命周期为 Idle → Enter → Hold → Returning → AwaitSync → Idle。
7. Returning 在 ExitSeconds 内返回每帧新计算的玩家基础 POV，持续移动不延时。完成时置同步标志；下一次 ProcessControlRotation 读取上一轮完整相机缓存并输出差值。由于执行顺序，通常延后一帧，不是同帧同步。AwaitSync 是一次控制更新交接，不等待移动归零；控制更新暂停时它也会等待，不应声称无条件零延迟。
8. UGC 的两个控制旋转钩子返回值做 AND。本版同时实现 ModifyFullControlRotation 并保留 bBlockRotationThisCall，防止 Reset 后本次阻断失效。同步结果仍受 Camera Manager 最终角度限制约束。
9. 上游移动计算通常先于 UpdateRotation，同步可能影响下一次移动采样；这符合选择 ProcessControlRotation 的时序代价。Returning 完成后，即使 Move 持续，方向也将采用同步后的 ControlRotation。

## Hard 的逻辑虚拟 ViewTarget

Target 是弱引用，是本地逻辑目标，不是真实 ViewTarget，也不是代理 Actor。Hard 的目标机位仅使用目标点、目标初始 Yaw 和 Preset；不使用玩家 Location 或 ControlRotation。世界点目标使用世界 Yaw 0 加预设 YawOffset。初始玩家 Camera POV 仅用于平滑进入的起点，Returning 的玩家 POV 仅用于退出终点，不参与 Hard 保持机位。目标移动时只重新取目标点、保持观察侧，不实现输入环绕目标。

玩家 Pawn 仍是 Gameplay 上下文；碰撞查询可忽略玩家 Actor，但不使用玩家位置确定 Hard 构图。

## 已知边界

代码为未编译、未实机验证的参考实现。Solve 检查目标机位构图与碰撞，但过渡路径/Returning 的 sweep、碰撞后的双目标构图复核仍需补全。Soft 首帧双目标未入镜时不能同时保证连续转向与全程入镜，需要请求筛选。Hold 直接重新求解机位，未加入目标跟踪阻尼。

后续 UGC Collision 可能以玩家为安全点修正 Hard 机位，必须按项目关闭不适用的碰撞路径或采用 Guidance 内部路径检测；不能仅靠返回 true 截断全部下游 Modifier。当前返回 false 保留链，不承诺最终机位不会被后续效果改变。同步读取实际缓存，可能包含 Camera Shake；若不希望控制旋转吸收震动，应定义无震动参考旋转并调整顺序。

Hard 目标独立构图仅支持标准透视与当前宽高比模型；分屏约束、非默认重力、角色换 Pawn、瞬移和高优先级控制器行为需要项目验证。Returning 终点使用进入本 Modifier 前的当前玩家 POV，绝不能用上一帧的 Guidance CameraCache 作为终点，否则会向自身插值。
