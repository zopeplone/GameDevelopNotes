# UE5.8 蒙太奇编辑器搭建详解与技能编辑器实现指南

本文以 UE 5.8 源码为依据，解释 Persona/AnimationEditor 中的 Montage Editor 是怎样从资产打开一路搭建到 Slate 时间轴的，并将这套方法转换成漫威争锋风格技能编辑器的工程方案。

## 1. 先看完整调用链

打开一个 `UAnimMontage` 时，主要链路如下：

```text
AssetEditorSubsystem
  -> FAnimationEditor::InitAnimationEditor
     -> FPersonaModule::CreatePersonaToolkit
        -> IPersonaToolkit / IPersonaPreviewScene
     -> FAnimationEditor::InitAssetEditor
     -> FAnimationEditorMode::RegisterTabFactories
     -> OpenNewAnimationDocumentTab
        -> 文档页创建 SMontageEditor
           -> FAnimModel_AnimMontage::Initialize
           -> SAnimEditorBase::Construct
              -> SAnimTimeline::Construct
                 -> FAnimTimeSliderController
                 -> SAnimOutliner + SAnimTrackArea
                 -> Sections/Montage/Timing/Notify Tracks
```

这个顺序很重要：**Toolkit 管生命周期和 Tab，PreviewScene 管可视化对象，Model 管可编辑数据，Timeline 管 Slate 交互，Track 管单条轨道，Details 管属性代理**。技能编辑器也应保持这个职责边界。

## 2. AnimationEditor 入口如何工作

源码文件：`Engine/Source/Editor/AnimationEditor/Private/AnimationEditor.cpp`。

### 2.1 `InitAnimationEditor`

`FAnimationEditor::InitAnimationEditor` 做了六件事：

1. 保存当前 `UAnimationAsset`，注册重导入回调；
2. 组装 `FPersonaToolkitArgs`，调用 `FPersonaModule::CreatePersonaToolkit`；
3. 将 PreviewScene 默认模式设置为 Animation；
4. 创建 SkeletonTree，并把选择改变回调绑定到编辑器；
5. 调用 `FAssetEditorToolkit::InitAssetEditor` 创建独立/世界中心编辑器；
6. 绑定命令、添加 `FAnimationEditorMode`、切换当前模式、扩展菜单/工具栏并打开动画文档 Tab。

这意味着 Montage Widget 本身不负责创建世界、资产编辑器窗口或 SkeletonTree。复刻技能编辑器时，不要在 `SMarvelAbilityEditor` 构造函数里创建 World 和 Details；这些对象应由 Toolkit 统一拥有。

### 2.2 Persona Toolkit 的作用

Persona Toolkit 为编辑器提供：

- `IPersonaPreviewScene`：预览世界、Preview Pawn、`UDebugSkelMeshComponent`、动画实例；
- `IEditableSkeleton`：Slot、Skeleton、骨骼和预览网格；
- Preview Mesh/Anim Blueprint/附加网格管理；
- 预览播放、相机、风、LOD、Socket/Bone 选择事件。

技能编辑器不应依赖 Persona 私有头文件。它应作为 Marvel 项目内部功能，运行时直接使用项目已有的 `MarvelAbilityItem`、`AnimTimeline`、Ability Config 与执行系统；只把 Toolkit、Slate、Details Proxy 和预览辅助类放进项目的 Editor-only 模块。预览场景可以通过公开的 `FPreviewScene`、`UDebugSkelMeshComponent` 和 `UAnimSingleNodeInstance` 组合。

## 3. ApplicationMode 与 Tab 布局

源码文件：`Engine/Source/Editor/AnimationEditor/Private/AnimationEditorMode.cpp`。

`FAnimationEditorMode` 继承 `FApplicationMode`，在构造时填充 `ApplicationModeTabFactories`：SkeletonTree、Details、Viewport、AdvancedPreview、AssetBrowser、AssetDetails、CurveViewer、Notify、Montage Sections、Find/Replace、Attribute Viewer 等。

布局是由 `FTabManager::NewLayout` 构造的嵌套 Splitter/Stack：左侧约 20% 放骨骼和资产详情，中间约 60% 放 Viewport 与 Document，右侧约 20% 放 Details、Preview Settings 和 Asset Browser。底部的 Document Tab 是 `SMontageEditor` 的宿主。

### 3.1 技能编辑器 Tab 设计

建议创建 `FMarvelAbilityEditorMode`：

```text
左侧 22%：Ability Browser / Cue Browser / 关联资产树
中间上 58%：Preview Viewport
中间下 58%：Timeline Document
右侧上 20%：Details（节点、Ability、Buff、Scope）
右侧下 20%：Sections / Validation / Dependency
```

使用固定 Tab ID，例如 `MarvelAbilityViewport`、`MarvelAbilityTimeline`、`MarvelAbilityDetails`、`MarvelAbilitySections`。布局版本号必须递增，例如 `MarvelAbilityEditor_Layout_v1`，避免修改布局后旧用户配置无法迁移。

## 4. `SMontageEditor` 的最小职责

源码文件：`Engine/Source/Editor/Persona/Private/SMontageEditor.cpp/.h`。

`SMontageEditor::Construct` 的实际代码非常短，核心只有这些步骤：

```cpp
MontageObj = InArgs._Montage;
check(MontageObj);

AnimModel = MakeShared<FAnimModel_AnimMontage>(
    InRequiredArgs.PreviewScene,
    InRequiredArgs.EditableSkeleton,
    InRequiredArgs.CommandList,
    MontageObj);

AnimModel->OnSelectObjects = FOnObjectsSelected::CreateSP(
    this, &SAnimEditorBase::OnSelectionChanged);
AnimModel->OnSectionsChanged = InArgs._OnSectionsChanged;
AnimModel->OnInvokeTab = InArgs._OnInvokeTab;
AnimModel->OnEditCurves = ...;
AnimModel->Initialize();

MontageObj->RegisterOnMontageChanged(
    UAnimMontage::FOnMontageChanged::CreateSP(
        AnimModel.Get(), &FAnimModel_AnimMontage::RefreshTracks));

SAnimEditorBase::Construct(
    SAnimEditorBase::FArguments().AnimModel(AnimModel),
    InRequiredArgs.PreviewScene);
```

它没有直接创建每一个 Notify 小控件。它只负责把 Montage 资产、Montage Model、选择回调和父类时间轴接起来。析构时注销 `OnMontageChanged`，防止资产销毁后回调悬空。

技能编辑器应照此设计：

```cpp
void SMarvelAbilityEditor::Construct(
    const FArguments& Args,
    const FMarvelAbilityEditorRequiredArgs& Required)
{
    AbilityItem = Args._MarvelAbilityItem;
    Model = MakeShared<FMarvelAbilityEditorModel>(
        Required.PreviewScene,
        Required.CommandList,
        AbilityItem);
    Model->OnSelectObjects = FOnObjectsSelected::CreateSP(
        this, &SMarvelAbilityEditor::HandleSelectionChanged);
    Model->Initialize();
    AbilityItem->OnAbilityItemChanged.AddSP(Model.Get(),
        &FMarvelAbilityEditorModel::RefreshFromAbilityItem);
    SMarvelAbilityEditorBase::Construct(
        SMarvelAbilityEditorBase::FArguments().EditorModel(Model),
        Required.PreviewScene);
}
```

这里的 `SMarvelAbilityEditorBase` 是项目 Editor 模块内的公共基类，不要继承 Persona 私有 `SAnimEditorBase`。Model 构造时从 `MarvelAbilityItem.TimelineToPlayMontage` 取得现有 `AnimTimeline`，而不是创建另一种 Timeline 资产。

## 5. `SAnimEditorBase` 如何装配时间轴

源码文件：`Engine/Source/Editor/Persona/Private/SAnimEditorBase.cpp`。

父类完成以下工作：

1. 保存 PreviewScene 和对象选择回调；
2. 用对象播放长度初始化 View Range；
3. 根据 `DisplayAnimTimeline` 创建 `SAnimTimeline`；
4. 将时间轴和额外的编辑面板放进 Overlay；
5. 按需在底部创建 `SAnimationScrubPanel`；
6. 用 `EditorObjectTracker` 创建 Details 可编辑包装对象；
7. 从 PreviewScene 的 `UAnimSingleNodeInstance` 读取和设置当前时间。

技能版公共基类至少应拥有：

```cpp
class SMarvelAbilityEditorBase : public SCompoundWidget, public FGCObject
{
protected:
    TWeakPtr<FMarvelAbilityEditorModel> Model;
    TWeakPtr<FMarvelAbilityPreviewScene> PreviewScene;
    TSharedPtr<SMarvelAnimTimeline> TimelineWidget;
    FOnObjectsSelected OnObjectsSelected;
    FMarvelAbilityEditorObjectTracker EditorObjectTracker;

    virtual float GetSequenceLength() const;
    virtual void SetScrubTime(double Seconds);
    virtual UObject* ShowInDetailsView(const FGuid& SelectionId);
};
```

`FMarvelAbilityEditorObjectTracker` 的职责是让一个 `AnimTimeline` 事件、Section、`ExtendConfigInline` 或关联 DataTable Row 变成临时 `UObject`，以便 `IDetailsView::SetObjects` 使用。代理对象要保存 `MarvelAbilityItem`、`AnimTimeline` 与源表行的弱引用/稳定 ID，不要复制一份脱离源数据的属性。

## 6. `SAnimTimeline` 的组成

源码文件：`Engine/Source/Editor/Persona/Private/AnimTimeline/SAnimTimeline.cpp`。

### 6.1 时间模型

`SAnimTimeline::Construct` 先保存 `FAnimModel`，绑定 PreviewInstance 的 KeyComplete 回调，然后创建：

- ViewRange、PlaybackRange、ClampRange 三种范围属性；
- DisplayRate 与 TickResolution；
- `FFrameNumberInterface` 数值输入；
- `FTimeSliderArgs`；
- `FAnimTimeSliderController`；
- `SequencerWidgets` 模块提供的顶部 TimeSlider 和底部 TimeRange；
- `SAnimTrackArea`、`SAnimOutliner`、滚动条；
- Outliner 搜索框、当前播放时间 SpinBox、Transport Controls、两个 Overlay 和可拖动分栏。

关键点是 ViewRange 等属性用 Lambda 绑定到 Model，而不是在 Widget 中缓存一份时间。Model 改变后，滑块和轨道自动刷新。

### 6.2 时间轴布局

Slate 结构可以简化成：

```text
SOverlay
  └─ SVerticalBox
       └─ SGridPanel
            ├─ (0,0) Outliner 搜索 + 当前时间输入
            ├─ (1,0) TopTimeSlider
            ├─ (0,1) SAnimOutliner
            ├─ (1,1) SAnimTrackArea
            ├─ (1,1) TickLine Overlay
            ├─ (1,1) ScrubPosition Overlay
            ├─ (0,3) Transport Controls
            └─ (1,3) BottomTimeRange
```

技能版 `SMarvelAnimTimeline` 可直接照这个布局写。这里的名称只表示编辑器 Widget；它编辑的资产仍是项目已有 `AnimTimeline`。不要把轨道数组直接放在 `SListView` 中；Outliner 和 TrackArea 必须共享行模型和滚动状态，否则折叠、滚动、选中会错位。

### 6.3 必须实现的交互

- 左侧搜索过滤轨道；
- 当前时间以秒/帧显示并可直接输入；
- 鼠标拖动播放头调用 `SetScrubTime`；
- 缩放只改变 ViewRange，不改变资产时间；
- ClampRange 限制可编辑边界；
- SnapTimes 提供 Section、事件开始/结束、帧和自定义标记；
- Outliner/TrackArea 分栏可拖动并保存比例；
- 右键菜单接入命令列表，统一支持 Copy/Paste/Delete。

## 7. `FAnimModel_AnimMontage` 如何生成轨道

源码文件：`Engine/Source/Editor/Persona/Private/AnimTimeline/AnimModel_AnimMontage.cpp`。

### 7.1 初始化

构造函数把 Montage 转为 `UAnimMontage*`，注册 `CompositeSegment` 与 `MontageSection` 两种 SnapType，并默认打开 Timing Element 显示。`Initialize` 先调用父类，再注册 Skeleton Slot 变化回调。

### 7.2 `RefreshTracks`

实现顺序如下：

```text
ClearTrackSelection
ClearRootTracks
创建/复用 FAnimTimelineTrack_Montage 根轨道
创建 FAnimTimelineTrack_MontagePanel
创建 FAnimTimelineTrack_TimingPanel
RefreshNotifyTracks
RefreshCurveTracks
RefreshSnapTimes
RefreshSectionTimes
广播 OnTracksChangedDelegate
UpdateRange
```

这种“全量重建轻量 Track 对象”的策略比每次增量修补 Slate 更稳定。技能版可以全量重建轨道树，但应保留选中事件的 `FGuid`，刷新后按 Identity 恢复选择。

### 7.3 Section 拖动的完整语义

`OnSetEditableTime` 在非拖动结束时：

1. 创建 `FScopedTransaction`；
2. `AnimMontage->Modify()`；
3. 设置 `FCompositeSection::SetTime`；
4. 调用 `Section.Link(AnimMontage, Time)`；
5. `SortSections()`；
6. `RefreshNotifyTriggerOffsets()`；
7. `PostEditChange()`、`MarkPackageDirty()`；
8. 广播轨道刷新。

`SortSections` 还会确保存在起始 Section，并触发 `OnSectionsChanged`。技能版 Section 应保留同样的流程，且额外检查节点时间和分段引用。

### 7.4 长度变化

`RecalculateSequenceLength` 先 `InvalidateRecursiveAsset`，计算 Montage 实际长度；缩短时 `ClampToEndTime` 把超出范围的 Section/Notify 移到末尾，更新 Notify Offset，再设置 CompositeLength、UpdateRange，并把 PreviewInstance 当前时间重新 Clamp。技能版修改 SequenceLength 时也必须处理事件和调试对象，否则会出现时间轴可见但运行时永远不触发的节点。

## 8. Track、Panel 和 Node 的分工

### 8.1 `FAnimTimelineTrack`

Track 是数据到 UI 的适配对象，负责父子层级、排序、可见性、高度、Tooltip 和生成 Outliner/Timeline 容器。它不应该拥有资产所有权。

技能版基类：

```cpp
class FMarvelAnimTimelineTrack : public TSharedFromThis<FMarvelAnimTimelineTrack>
{
public:
    virtual TSharedRef<SWidget> GenerateOutlinerWidget(...) = 0;
    virtual TSharedRef<SWidget> GenerateTimelineWidget(...) = 0;
    virtual void BuildContextMenu(FMenuBuilder& Menu);
    virtual FReply HandleMouseDown(...);
    virtual void RefreshChildren();
};
```

### 8.2 Montage Panel

`FAnimTimelineTrack_MontagePanel` 的构造函数按 Slot 数量设置高度；Outliner 为每个 Slot 生成固定高度行，显示 Group.Slot 名称、警告图标和 Slot 菜单。菜单支持改 Slot、New/Delete/Duplicate、Preview Slot 和 Slot Manager。

技能版对应 `FMarvelAnimTimelineTrack_AbilityPhases`：每个 Ability Phase 或逻辑层固定一行，显示阶段名、Tag、权限和启用状态，菜单支持创建/复制/删除/预览阶段。

### 8.3 Notify Panel

`SAnimNotifyPanel`/`SAnimNotifyTrack` 负责瞬时 Notify、NotifyState、轨道管理、框选、替换类、复制/粘贴和详情选择。创建 Notify 时源码使用 `FScopedTransaction`、资产 `Modify()`，填充 `FAnimNotifyEvent`，调用 `OnAnimNotifyCreatedInEditor`，然后 `PostEditChange` 和 `MarkPackageDirty`。

技能版应将 `CreateNewNotifyAtCursor` 接到项目已有 `AnimTimeline` Notify 数据：在光标时间创建该资产所使用的 Notify Event 结构，实例化 `AnimNotify_SpawnScope`、`AnimNotify_ApplyBuff` 等已有节点 UObject，初始化默认字段与 Identity，再刷新 Model。不要另建平行的通用 Timeline Event 并做二次转换。

## 9. PreviewScene 是如何搭建的

源码文件：`Engine/Source/Editor/Persona/Private/AnimationEditorPreviewScene.cpp/.h`。

`FAnimationEditorPreviewScene` 继承 `IPersonaPreviewScene`，构造时：

- 向 GEditor 注册 Undo；
- 创建 `UPersonaPreviewSceneDescription`，保存 PreviewMesh、Preview AnimBP 和附加网格；
- 创建默认 `UPreviewMeshCollection`；
- 关闭 World Bounds 检查；
- 为预览世界申请独立 AudioDevice；
- 创建/维护 Actor、`UDebugSkelMeshComponent` 和附加网格；
- 绑定骨骼、Socket、Mesh Click、PreTick/PostTick、LOD 和视口失效回调；
- 在换网格时保持当前动画、播放位置和播放状态。

### 9.1 技能 PreviewScene 最小版

第一版不需要复制 Persona 的风、录制、布料和 SkeletonTree。只实现：

```cpp
class FMarvelAbilityPreviewScene : public FPreviewScene, public FTickableEditorObject
{
    TObjectPtr<AActor> PreviewActor;
    TObjectPtr<UDebugSkelMeshComponent> MeshComponent;
    TObjectPtr<UMarvelAbilitySystemComponent> PreviewASC;
    TWeakObjectPtr<UObject> TimelinePlaybackObject; // 项目已有 AnimTimeline 播放器/Task
    TArray<TSharedPtr<IMarvelAbilityDebugDrawer>> DebugDrawers;
};
```

创建 `UWorld` 后生成 PreviewActor，挂 SkeletalMeshComponent，设置 `VisibilityBasedAnimTickOption = AlwaysTickPoseAndRefreshBones`，使用 `UAnimSingleNodeInstance` 或专用 PreviewAnimInstance 播放 Montage。每次换英雄/皮肤先停止 Player、清理 ASC 效果和调试对象，再替换网格和动画类。

### 9.2 Preview Tick 顺序

```text
PreviewScene::Tick
  -> PreviewAnimInstance 更新 Montage
  -> 项目已有 AnimTimeline 播放器/AbilityTask 推进逻辑时间
  -> Scope/Projectile/Cue DebugDrawer 绘制
  -> 广播视口刷新
```

若 Montage 和 `AnimTimeline` 使用不同 Tick，必须明确谁是主时钟；编辑器应调用项目运行时已有的同步/跳转入口，而不是在 Editor 模块再实现一套 DeltaTime 调度。

## 10. Details、选择和 Undo/Redo

### 10.1 选择流

```text
Node/Section 点击
  -> Model.SetSelection(FGuid)
  -> Model 创建 EventProxy/SectionProxy
  -> OnSelectObjects 广播 UObject 数组
  -> Toolkit 的 IDetailsView::SetObjects
```

Persona 还把 SkeletonTree 选择路由到 EditorModeManager 的 TypedElement SelectionSet。技能编辑器可先用自己的 `FMarvelAbilitySelectionSet`，以后再适配 Typed Elements。

### 10.2 事务模板

所有编辑操作都遵循：

```cpp
const FScopedTransaction Transaction(LOCTEXT("MoveAbilityEvent", "Move Ability Event"));
Ability->Modify();
Timeline->Modify();
Event.StartTime = NewTime;
Timeline->SortAndRefresh();
Timeline->PostEditChange();
Timeline->MarkPackageDirty();
Model->BroadcastChanged();
```

拖动过程中可以只更新预览值，鼠标释放时提交一次事务；否则一次拖动会生成数百条 Undo 记录。

`FMarvelAbilityPreviewScene` 应实现 `FEditorUndoClient::PostUndo/PostRedo`，撤销后重新加载项目 `AnimTimeline` 播放对象、清空活动 State、恢复当前时间并刷新 DebugDrawer。

## 11. 技能编辑器的推荐类图

```text
FMarvelAbilityEditorToolkit : FAssetEditorToolkit
  ├─ FMarvelAbilityEditorMode : FApplicationMode
  ├─ FMarvelAbilityPreviewScene : FPreviewScene
  ├─ FMarvelAbilityEditorModel
  │    ├─ FMarvelAnimTimelineTrack
  │    ├─ FMarvelAnimNotifyTrack
  │    └─ FMarvelAbilitySelectionSet
  ├─ SMarvelAbilityDocument
  │    ├─ SMarvelAnimTimeline
  │    ├─ SMarvelAnimTimelineOutliner
  │    └─ SMarvelAnimTimelineTrackArea
  └─ IDetailsView + UObject Proxy
```

`MarvelAbilityItem`、`AnimTimeline`、Config、AbilityTask 和 ASC 保持在项目现有运行时模块。新增的 Model/Track/Slate/Details Proxy 放在项目 `Source/MarvelAbilityEditor`（或现有 Marvel Editor 模块）中，并在 Target/uproject 中仅为 Editor Target 加载。不要迁移或包装一份运行时资产，也不要让现有运行时头文件包含 `Slate.h`、`UnrealEd.h` 或 `PropertyEditorModule.h`。

## 12. 技能编辑器打开流程

### 12.1 资产注册

为现有 `MarvelAbilityItem` 类型实现 `UAssetDefinition_MarvelAbilityItem`，或在已有资产定义上更换 `OpenAssetEditor`：

- 支持的资产类是项目真实的 `MarvelAbilityItem` UObject 类；
- 打开操作 `OpenAssetEditor`；
- 图标、分类和颜色；
- 是否支持批量打开。

### 12.2 Toolkit 初始化

```cpp
void FMarvelAbilityEditorToolkit::InitEditor(
    const EToolkitMode::Type Mode,
    const TSharedPtr<IToolkitHost>& Host,
    UMarvelAbilityItem* InAbilityItem)
{
    AbilityItem = InAbilityItem;
    Preview = MakeShared<FMarvelAbilityPreviewScene>(AbilityItem);
    Model = MakeShared<FMarvelAbilityEditorModel>(AbilityItem, Preview);
    Model->Initialize();

    FAssetEditorToolkit::InitAssetEditor(
        Mode, Host, MarvelAbilityEditorAppIdentifier,
        FTabManager::FLayout::NullLayout,
        true, true, InAbilityItem);

    AddApplicationMode(
        MarvelAbilityModes::AbilityEditorMode,
        MakeShareable(new FMarvelAbilityEditorMode(SharedThis(this))));
    SetCurrentMode(MarvelAbilityModes::AbilityEditorMode);
}
```

### 12.3 Document Tab

Document Tab 的 Spawn 函数创建 `SMarvelAbilityDocument`，传入 Model、PreviewScene、CommandList 和回调。Model 从 `MarvelAbilityItem` 解析 `TimelineToPlayMontage`、`ExtendConfigInline`、`GrantedAbility` 和各类 ID 引用。Tab 关闭时只释放临时 Preview/Proxy，不销毁这些项目资产。

## 13. Timeline Model 的实现顺序

1. 定义 `GetSequenceLength`、`GetFrameRate`、`GetTickResolution`、`GetViewRange`、`GetPlaybackRange`、`GetWorkingRange`。
2. 实现 `RefreshTracks`，建立稳定的 Root/Children 树。
3. 实现 `RefreshSnapTimes`，加入 Section、事件开始/结束、帧边界。
4. 实现 `SetScrubPosition`，同步 Preview Montage 和 Timeline Player。
5. 实现选中、框选和 Outliner 过滤。
6. 实现 `OnSetEditableTime`、Resize、Add/Delete、Replace、Paste。
7. 实现 Details Proxy 和源对象写回。
8. 最后加入 Cue/Scope/Projectile 的预览绘制和运行时执行。

## 14. 节点工厂和可扩展性

定义一个注册表：

```cpp
struct FMarvelAnimTimelineNodeDescriptor
{
    FName TypeId;
    FText DisplayName;
    FLinearColor Color;
    TSubclassOf<UAnimNotify> NotifyClass;           // 或项目 AnimTimeline 的已有 Notify 基类
    TSubclassOf<UAnimNotifyState> StateClass;
    TFunction<void(UObject* Proxy)> InitializeDefaults;
    TFunction<void(const FMarvelAbilityPreviewContext&)> DrawPreview;
    TFunction<FMarvelAbilityExecuteResult(const FMarvelAbilityExecuteContext&)> Execute;
    TFunction<void(const FMarvelAnimTimelineEventView&)> Validate;
};
```

`AnimNotify_TagNotify`、`MarvelTagNotify_Missile`、`AnimNotify_SpawnScope` 等解包类型分别注册 descriptor。策划从菜单选择 descriptor，编辑器自动创建对应 Payload；运行时只调用 Execute，不依赖 Slate。

## 15. UE5.8 版本与 API 边界

UE 源码中的 `SMontageEditor`、`SAnimTimeline`、`FAnimModel_AnimMontage` 位于 Persona 的 `Private` 目录，即使这是项目内部 Editor 模块也不能把它们当作稳定公共 API。可复用的是架构和公开类型：

- `FAssetEditorToolkit` / `FWorkflowCentricApplication`；
- `FApplicationMode` / `FTabManager`；
- `IDetailsView` / `FPropertyEditorModule`；
- `FPreviewScene`、`UDebugSkelMeshComponent`、`UAnimSingleNodeInstance`；
- `FScopedTransaction`、`FEditorUndoClient`；
- `FUICommandList`、`ToolMenus`、`AssetRegistry`；
- `SequencerWidgets` 的 TimeSlider 接口（确认项目 Editor 模块可以依赖）。

如果必须使用 Persona 的公开接口，先在编译器中确认对应头文件位于 `Persona/Public`，并通过模块 API 宏导出；否则复制概念并实现自有类。

## 17. 分阶段实现与验收

### 阶段一：Montage 核心

完成资产工厂、Toolkit、PreviewScene、Document Tab、Timeline、一个 Track 和一个事件。验收：能打开资产、播放 Montage、拖动播放头、保存和撤销。

### 阶段二：完整编辑器交互

完成 Sections、Outliner、拖动/缩放、吸附、框选、复制/粘贴、Replace、Details Proxy、布局持久化。验收：编辑操作不会产生悬空引用，Undo 一次撤销一次用户动作。

### 阶段三：技能原语

完成 Tag、ApplyBuff、SpawnScope、SpawnProjectile、Camera 和 Cue 节点。验收：预览可以显示几何并触发测试 Cue，运行时事件顺序与编辑器一致。

### 阶段四：GAS/网络

接入 ASC、Cost、Cooldown、PredictionKey、服务器命中校验和拒绝回滚。验收：预测失败能清理 State、Cue 和临时实体，不改变服务器权威属性。

### 阶段五：生产化

完成资产依赖扫描、引用重定向、批量校验、Cook 前报告、自动化测试和性能统计。验收：删除/重命名关联资产会得到明确错误，所有 Timeline 能在无编辑器环境加载和执行。

## 18. 最终搭建原则

1. 先搭 Toolkit/Mode/Tab，再搭 Document/Timeline，最后搭节点行为。
2. 先实现 Model API 和数据校验，再写 Slate 绘制；Widget 不直接修改数组。
3. 以 Montage/Timeline 的单一时钟驱动动画、逻辑和调试，避免多个 DeltaTime 累加器漂移。
4. 所有资产编辑遵守 `Modify -> 写入 -> Sort/Refresh -> PostEditChange -> MarkPackageDirty -> Broadcast`。
5. 节点是“配置 Payload + 运行时执行器 + 编辑器绘制器 + 校验器”的完整单元。
6. Persona 私有源码用于理解，不作为继承层；编辑器直接服务于项目已有 `MarvelAbilityItem`、`AnimTimeline` 和 Config 数据契约。
